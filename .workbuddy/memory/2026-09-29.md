   → 修法：classmethod 改名 `_configure_auth`；`ROOT /` 改 `os.path.join`。

### 本次踩坑（脚本层）
1. **容器内跑内联 python 会被 shell 吃掉转义**：`sh -c '... python3 -c "...\n..."` 的 `\n` 在多层引号里变形 → 解析全空却「无报错」。
   → 正解：**脚本经 stdin 传入** `docker exec -i pentest-webui python3 -`，用 `i.write(SCRIPT); i.channel.shutdown_write()`。
2. **传参含空格会被宿主 bash 词分割**：`python3 - ["a", "b"]` 里 argv[1] 变成 `["a",` → `JSONDecodeError`。
   → 传参一律 `shlex.quote(json.dumps(x))`。
3. 判据：脚本输出前加哨兵行（如 `@@JSON@@`），本地先断言哨兵存在再解析 —— 否则「无输出」和「解析失败」分不清。
