## 发布硬化（deploy hardening）

用户指令「做发布硬化」—— 把 Web 控制台从「仅本地回环、零认证」提升为可上服务器的形态。

### 改造 webui.py（+375/-19）
- **认证**：HMAC 签名 Cookie 登录（`_make_token`/`_verify_token`）；`REQUIRE_AUTH` 默认关闭（回环本地零摩擦，兼容离线靶场测试），仅非回环绑定或 `--require-auth` 时强制开启。
- **fail-closed**：非回环 + 无口令（ env `WEBUI_AUTH_PASSWORD` 或 `webui_auth.json` PBKDF2 哈希）→ 拒绝启动。口令用 `--set-password` 引导，文件 chmod 600。
- **_capture 并发**：新增全局 `_CAPTURE_LOCK`，进程级 stdout/stderr 重定向加锁，避免规则引擎扫描 vs coverage/lint 预演并发串台。
- **TLS**：`--tls-cert/--tls-key` 自终止；非回环未开 TLS 明文告警；TLS 时 Cookie 加 `Secure` + 响应加 `HSTS`。
- **安全响应头**：`end_headers` 注入 X-Content-Type-Options / X-Frame-Options: DENY / Referrer-Policy / CSP；混淆 `server_version="wbui"`。
- **日志轮转**：`--log-file`（RotatingFileHandler 5MB×5）+ 请求日志落盘；`--pid-file` 启动写、停机删。
- 登录失败每 IP 5 次/5 分钟锁定。

## 发布硬化第二轮（残留风险 + 启动崩溃修复）

第二轮做四项：多账户 / CSRF / 全局限流 / SIGTERM 优雅停机，并**修掉两个「启动即崩」缺陷**。

### ⭐ 两个 main() 崩溃缺陷（此前测试从不执行 main()，长期漏检）
1. **`ROOT` 是 `str`**（`os.path.dirname(...)`），argparse 默认值却写 `str(ROOT / "webui_secret.json")` → 解析参数即 `TypeError: unsupported operand /: 'str' and 'str'`。
2. **`Handler._load_auth` 定义两次**：2504 的 classmethod 被 2717 的同名 instance method 覆盖 → `Handler._load_auth(require_auth,...)` 传 4 参给 `(self)` → 非回环/`--require-auth` 启动崩溃。
   → 修法：classmethod 改名 `_configure_auth`；`ROOT /` 改 `os.path.join`。
   → **根因教训**：`_test_webui_lab.py` 用 `Handler.__new__` 直调 `api_*`，绕过了 `do_GET/do_POST` **和 main()** → 「单测全绿」≠「能启动」。新增 `_test_webui_startup_lab.py`（真实 subprocess 启动，19 断言）兜住 main() 全链路。

### 三项残留修复
- **多账户**：`webui_users.json`（`username→{salt,hash,role}`，PBKDF2）+ `--add-user <名> '<口令>' [--role]`；登录表单加用户名字段；token 体改为 `user|role|exp`（`_token_info` 兼容 2/3 段）；`USERS` 为 None 时回落单口令模式（兼容旧部署与测试）。
- **CSRF 双提交**：登录/主页下发 `wbui_csrf`（非 HttpOnly，JS 可读），所有写 POST 校验头 `X-CSRF-Token`==Cookie（不匹配 403）；`/api/login`、`/api/logout` 豁免；前端 `post()` 与 `upload_cred` 自动带头；`REQUIRE_AUTH=False` 时不启用（本地零摩擦不受影响）。
- **全局限流**：`_RateLimiter`（每 IP 滑动窗口），`do_GET/do_POST` 入口 `_rate_ok()` → 超限 429；默认 240/60s，`--rate-limit/--rate-window` 或 env `WEBUI_RATE_LIMIT`，0=关。
- 附带：`version_string()` 覆写去掉 Server 头尾空格（`wbui` 而非 `wbui `）；SIGTERM/SIGINT 处理器 → systemd 停机时 finally 清理 PID 文件。
