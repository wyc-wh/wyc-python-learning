## Web 控制台 / UI（详见 HANDBOOK 十五 / 十五之二）
- 合规闸 `sys.exit(2)` **静默杀死请求线程**（`SystemExit` 继承 `BaseException`，`socketserver` 只捕 `Exception`）→ 必须 `_capture()` 兜；只回退出码 = 没告诉原因，要从捕获日志挑 `[BLOCK]/[FAIL]` 行
- **Windows ADS**：`rules_x:port.json` 的 `:` 被 NTFS 当数据流 → 本体 0 字节而 `isfile()`/`getsize()` 全正常 → 一律走 `safe_evidence_name()`
- **PAGE 必须 raw string**：否则编译期把 JS 的 `\n` 解成真换行 → 单引号字面量折断、正则被提前处理。判据 = 断言 `join('\n')` 子串存在；拼接走脚本切片，替换前 assert 无 `"""`、末尾非反斜杠
- **前端也要门禁**：`node --check` 只取 `<script>` **标签之间**的 JS（带标签 = 非法 token）+ `$('#id')` 与内联 onclick 函数名一致性断言；node 缺失**显式 SKIP 且不计入通过**
- **视觉验证**：无头 Chrome 900 宽截图；看下半页用 wrapper `<iframe style="top:-1450px">` 裁剪。**`#锚点` 截图会「内容贴底 + 上方大片黑」，别据此判布局 bug**
- 驾驶舱数据后端驱动：风险四档**只计发现项**（`needs_follow_up` 是没查清，不是风险）；严重度**必须归一**（`High` vs `high`）；**越界拦截数只认审计链 BLOCK/REJECT**（`api_scope_check` 零副作用不写审计，否则虚增）
- **前端格式校验必须复用后端判据**（`orch.validate_scope`）：自造一套的假绿灯**比不校验更危险**
- 界面强制自律下限（≥6s / ≤10）并回显 `clamps`；**靶场 monkeypatch `webui.MIN_INTERVAL`**，不在生产代码开后门
- 凭证上传落盘名**由服务端生成**（`<sid>.authdoc.<白名单后缀>`），原名仅元数据 → 穿越面为零
- 遮罩只盖 `#gated`、**不盖阶段0**（唯一入口）；**完成反馈用 Toast 不用模态框** —— 每次弹会训练用户无脑点掉

- **不需核备案、不需事先报备**（"报备"只针对专属 SRC/众测）；**无资产白名单**。范围判据 = 官网首页公开链出 + 版权/主体一致；ICP 只作提交第 2 项「归属证明」

## 证据与工程纪律（详见 HANDBOOK 十四 · 全文 20+ 条，此处只留最易再犯）
1. **「缺失」与「值为 None」字面可区分**：缺失写 `<未声明>` + `*_present`。**属性不存在的中间表示不能复用「有值」的值域**（曾把缺失读成 `SameSite=None`，写出替厂商备好驳回理由的自我削弱附注）
2. **改了底层函数 ≠ 修好调用点** → 端到端复跑并比对原始输出
3. **异常响应先取证再下结论**：引擎只记状态码 + 字节数，**直觉两次被推翻**（疑似调试页实为 WAF 拦截页 / 疑似泄露实为站点自身 404 页）→ **按表象写就是幻觉发现**；**urllib 默认跟随 30x**，会把「明文 301」记成「200 不跳转」
4. **多值头会被 `dict(headers)` 截断**，且 **CSRF token ≠ 会话 Cookie**（同发 `XSRF-TOKEN` + `laravel_session` 时真会话 Cookie 会丢）→ Set-Cookie 单存 `_all_set_cookies`，两者正则必须互斥，否则「会话劫持链」被一句话驳回
5. **能被机器验证的写事实，不能验证的别写形容词**：「不跳转」→ 改，「返回完整内容」→ 实测 `{bytes}B`。「影响分析」由 CVSS 向量推出前提 + 影响。**写前自问：这句措辞在帮我还是在帮厂商？**
6. **隐私铁律**：凭据/密钥只记类别名 + 次数 + 值的长度与字符集，**不记值也不记其哈希**；API 响应只记字段名 / 条数 / sha256，**绝不记录返回值**
7. **靶场红时先分辨「数据脏」还是「代码错」，别改断言迁就**；**靶场必须自检 `status=None`**（忘 `verify_tls=False` 会让 HTTPS 全失败却表现为「站点没内容」→ **假通过**）
8. **禁 `python -c`/bash 内联写含反引号的中文长文本**（被当命令替换执行、内容静默挖空，踩过**两次**）→ 用 Write 写 `.py` 再执行；**规则数量从 `rules.load_rules()` 动态取**，别硬编码
9. **字典库原料「不读就信」是最大风险**：`HTTP/errors.txt` 曾误判为「WAF 特征表」，读原文才发现是 **SQL/框架报错串表** → 构建脚本**强制逐条定性**，漏/多/重复即拒绝生成
10. **「工具没装」先怀疑调用侧**：中文 Windows `encoding="utf-8"` 丢输出；端口列表别 `split()`。**耗时 = 超时整数倍 → 参数拼错；秒返空 → 编码问题**。nuclei **必须 `-no-interactsh`**（约 710 模板回连 `oast.*` 被网关掐断，零输出无提示）

## 判据与状态语义（详见 HANDBOOK 十一 闭环 / 十二 观测层 / 十三 判据库）
- **「排除项」是五种状态**：`no_issue_found`/`ruled_out`/`not_applicable`/`needs_follow_up`/`reported`。压成一个「排除」= 把「没拿到证据」读成「查过了没问题」。**`ruled_out` 缺 control 或 evidence 自动降级 `needs_follow_up`**（留 `_degraded_from`），**降级方向永远更保守**
- **只读下升 `ruled_out` 的唯一合法路径 = 横向事实**：多条**不同**路径返回**字节完全相同**的响应 → 机制可指名 + sha256 可核对（qmt：`.git/config` 与 `laravel.log` 均 404/11043B/同 sha256）。**边界**：只排除「这个 200 是文件内容」，**不解除**「文件是否存在」
- **「规则执行了」≠「检查面被覆盖」**：覆盖度分子已从「跑过没有」换成「**取得证据没有**」（资产 `_host_effective(h)`；规则 credit 未执行 0 / 只产待跟进 0.5 / 取得证据 1.0）。全站被 WAF 挡死时台账会写「已核查 8 个资产」实则连响应都没看到 → 进 `scope.hosts_weak` 单列
- **⚠️ 别把「规则维度低分」当观测层生效的证据** —— 三份真实产物上新旧口径读数完全相同（`ineffective=[]`），低分主因一直是「可达 13 条只跑了 1~4 条」
- **⭐ D-01 直接纠正本平台**：**不得仅因信息有助于侦察就给 `C:L`** —— 要**实际获取了受限信息**；版本 / source map / 路径**只是暗示**另一漏洞时，要么验完整链，要么保持 `C:N` 且**不提交该报告**。**D-02**：版本→CVE 三步，**第②步必须确认可达性**
- **R005 攻击面证据门槛**：厂商带 `_trigger_condition`（默认不触发）时**版本命中不足** → 从 `ctx.shared` 采上游事实（**0 额外请求**）；缺证据且在 `MAX_DEFERRED=3` 内 → **不产发现、改产待跟进**。**`ORDER` 里 R004 必须早于 R005**，否则看不到 `admin_no_captcha` 会把高危降级
- **lint 第二道闸**：EL030(澄清缺要件·阻断)/EL031(非法状态·阻断)/EL032(待跟进没写缺口)/EL033(未标状态)/EL034(发现缺反向论证)/EL035·EL036(外部排除判据 + `C:L` 无内容，警告级**不阻断提交**)
