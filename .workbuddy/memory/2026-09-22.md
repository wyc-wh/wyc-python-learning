### J-01 中危（CVSS3.1 6.8 / 4.0 6.4）`qmt.jiaoyu.cn`

四个安全响应头值为**字面量 `value`**（模板占位符未替换）：
```
Strict-Transport-Security: value
Referrer-Policy: value
X-Permitted-Cross-Domain-Policies: value
X-Download-Options: value
```
浏览器按无效指令忽略 → 防护全部失效。叠加明文 HTTP 200 不跳转 +
`laravel_session` 缺 Secure 且 SameSite=None → 会话劫持链闭合。

**定级要点**：「响应头缺失/失效」单独只有 3.1 分（低危）。
必须**三合一论证**（HSTS失效 + 明文可达 + Cookie缺Secure）才到 6.8。
拆开报会被判「影响不大」。

### ⭐ 新增可复用手法（4 条）

1. **安全头"占位符污染"检测** —— 值不是标准值而是 `value`/`off`/模板变量，
   说明配置写错。**比"缺失"更值得报**（运维误以为已防护，实际裸奔）。
   取证前先排除自己脚本的脱敏逻辑（我一开始怀疑是 manual_probe 干的，查证后确认是真实返回）

2. **用不存在的资源 ID 探测 DELETE/PUT 鉴权顺序** —— 零破坏取证。
   `DELETE /api/course/comment/999999999` → 若返回"未登录"说明鉴权在路由前（安全）；
   若返回"删除成功"/404 说明鉴权缺失。即使绕过也删不到真实数据

3. **SPA 兜底页识别软结果** —— `/.env` 返回 200 但体积与某 SPA 首页**完全一致**
   （都是 2056B）→ catch-all 兜底，**不是真泄露**。别被 200 骗（第二条）

4. **归属证明从前端 bundle 页脚取证** —— Vue/React SPA 无服务端页脚时，
   去 `app.<hash>.js` 里搜「版权所有 / ICP / 有限公司」。
   比查备案库更硬（站点自身声明），且一次拿全主体+地址+备案号
